PERFORMANCE RULES - THIS FIXES GPU SPIKE, MANDATORY:
1. Interval = 1000ms (1 second) everywhere. Use tea.Tick(time.Second) or time.NewTicker(time.Second). NO 100ms ticker.
2. Styles: ALL lipgloss.NewStyle() must be in internal/ui/styles.go as global vars. In View() only USE the var, don't create new.
3. NO exec.Command inside loop/tick for: nvidia-smi, nmcli, bluetoothctl, df, pactl list. Use direct file read / dbus. Exec only when user triggers action (e.g., user presses Enter to connect wifi).
4. Dbus connection is singleton from system/dbus.go
5. Monitor collectors send data via channel: type Collector struct { DataChan chan Stats }
6. UI redraws only when new data arrives, not forced full redraw.
